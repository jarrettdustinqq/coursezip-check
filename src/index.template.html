What this checks

  • ZIP directory structure and unsafe paths
  • Exact root imsmanifest.xml placement
  • Manifest checksum and well-formed XML
  • Declared resource/file paths, letter case, and identifier references
  • Package-relative paths, XML base paths, and external dependencies

Where the check stops

  • No SCORM certification or XML schema validation
  • No execution, full archive integrity scan, malware scan, or inspection of scripts and dynamically loaded assets
  • No LMS launch, completion, scoring, or accessibility test
  • ZIP64, encryption, split ZIPs, symlinks, legacy filename encodings, DTDs, and sub-manifests are unsupported
  • Limits: 10,000 ZIP entries, 4 MiB directory, 2 MiB manifest, 30,000 XML elements, 300 displayed findings per package
